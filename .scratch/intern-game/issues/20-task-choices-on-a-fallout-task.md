# Task choices on a Fallout Task

Type: grilling
Status: resolved
Blocked by: 19

## Question

Which Task choices does a Fallout Task offer, and what does ignoring one mean?

A Fallout Task takes 4 hours and follows the "Do it" row. The rules do not say whether the Intern can fake, delegate or sabotage it.

Decide:

- Whether faking a Fallout Task is allowed, and whether it creates more Fallout.
- Whether delegating it is allowed, and what each Colleague does with it.
- Whether sabotaging it is allowed, and what happens to the Task.
- What "ignoring" a Fallout Task means. For example, leaving it open at the end of the day.
- Whether ignoring it costs both the Fallout penalty (Performance 2) and the unhandled-Task penalty (Performance 1), and whether either repeats each night.
- Whether an ignored Fallout Task rolls over.

Source: [Pressures and Task choices](07-pressures-and-task-choices.md).

## Comments

- From [What sabotage does to a Task](19-what-sabotage-does-to-a-task.md): sabotage closes a Task without finishing it, and it never rolls over or returns. Decide whether a sabotaged Fallout Task follows the same rule.

## Answer

A Fallout Task offers all four Task choices, but the Intern cannot fake it twice. An ignored Fallout Task costs once and then expires.

### Task choices on a Fallout Task

All four Task choices still appear. Faking is locked.

| Task choice | Allowed | What happens |
| --- | --- | --- |
| Do it | Yes | 4 hours. The other effects follow the "Do it" row. |
| Fake it | No | Locked. The game shows the reason: "You already faked this once." |
| Delegate it | Yes, except to Ryszard | Normal delegation rules: 1 hour, the Colleague's Faction needs goodwill 5 or more, and that Faction loses 1 goodwill. |
| Sabotage it | Yes | The normal sabotage row. The Task closes for good and never returns. |

Delegating a Fallout Task works like delegating any Task:

- **Wiola Ufna** does it properly. The Task side Faction gains 1 goodwill.
- **Kamil Przeciek** escalates it. A Launch Team Fallout Task flips to the Paper Trail, as with any Launch Team Task.
- **Ryszard Szablon** is locked. The game shows the reason: "Ryszard already faked this once."

So no Fallout Task ever creates more Fallout.

### Ignoring a Fallout Task

- A Fallout Task is **ignored** when it is still unhandled at the end of the day it arrived.
- An ignored Fallout Task costs Performance 2 and adds 1 Escalation.
- It does not also pay the normal unhandled-Task cost of Performance 1. The total is Performance 2.
- It then **expires**: it closes for good and does not roll over. It is neither handled nor finished.

### Task growth

Doing or delegating a Fallout Task finishes it, so it counts toward Task growth like any finished Task. Sabotage handles it without finishing it.

### Rejected options

- **Faking allowed, with no new Fallout.** Every Fallout Task would cost only 1 hour, so faking would never hurt.
- **Faking allowed, with Fallout again.** This needs a second set of Fallout text and stacks badly late in the week.
- **Ignored Fallout costs Performance 3.** That charges twice for one mistake.
- **Ignored Fallout rolls over and repeats nightly.** This becomes a slow, certain Firing.
- **Ignored on any day, not only the arrival day.** Fallout is urgent by design, so it gets one day.

Glossary terms updated in `CONTEXT.md`: Fallout (cannot be faked, expires if ignored) and Expired (new).
- From [Survivability and the scripted week](25-survivability-and-the-scripted-week.md): an ignored Fallout Task now costs Performance 3, not 2. With 2, a player who fakes everything survived the week.
