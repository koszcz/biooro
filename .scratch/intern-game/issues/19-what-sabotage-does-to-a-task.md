# What sabotage does to a Task

Type: grilling
Status: resolved
Blocked by:

## Question

Does a sabotaged Task close, or does it stay open?

The rules say sabotage "does not finish" the Task. If it stays open, it rolls over and costs Performance 1 every night until the week ends. The Intern could also sabotage it again for more goodwill and Escalation.

Decide:

- Whether a sabotaged Task closes, stays open, or returns later like Fallout.
- Whether it counts as finished for the Task growth rule ("1 more Task for every 2 finished").
- Whether the same Task can be sabotaged twice.

Source: [Pressures and Task choices](07-pressures-and-task-choices.md).

## Answer

A sabotaged Task closes for good. It does not count as finished.

### What happens to the Task

- Sabotage closes the Task. It leaves the Intern's list at once.
- A sabotaged Task never rolls over, so it never costs the nightly Performance 1 for unhandled Tasks.
- A sabotaged Task never comes back later. Only faking creates Fallout.
- The Intern cannot sabotage the same Task twice, because it is gone.
- The costs in the Task choice table are the whole price of sabotage: 2 hours, Performance −1, Task side goodwill −2, rival goodwill +1, Sanity +1, and Escalation +1.

### Handled and finished

The rules now use two words:

- **Handled**: the Intern made any Task choice on the Task. A handled Task closes.
- **Finished**: the Intern did, faked or delegated the Task.

Sabotage handles a Task but does not finish it. So:

- Task growth counts only finished Tasks. Sabotage adds nothing to the next morning's Tasks.
- The rollover rule counts only unhandled Tasks. A sabotaged Task is handled, so it never rolls over.

### Rejected options

- **The Task stays open.** The Intern could sabotage it every day to farm rival goodwill and Escalation. It would also stack a nightly Performance cost, so sabotage would become a slow Firing.
- **The Task returns later, like Fallout.** This copies Fallout without adding a new idea.
- **Sabotage counts as finished.** This would break the current Task growth wording and remove a small reward for chaos: fewer new Tasks.

Glossary terms updated in `CONTEXT.md`: Task choice (sabotage closes the Task) and Handled (new).
