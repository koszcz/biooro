# Audio sources

Every file here is a placeholder. I made each one with `scripts/make-audio.sh` (ffmpeg tone and chord generators), run once by hand. I wrote the sounds, so they have no outside licence. The game never makes sound in code.

No file was downloaded. The spec names the Kenney audio packs (CC0). To swap one in, copy the file over the same name, run `npm run check:audio`, and add a line below with the file, the pack, the URL and the licence.
